# Example tasks

Three small tasks in two domains (`data-cleanup/ledger-reconcile`, `data-cleanup/contacts-dedupe`, `writing/release-notes`), each in the format described in the main README under "Tasks". Each one is solvable by Claude Code in a few minutes. `ledger-reconcile` carries a deterministic `check.py` and the other two carry a `rubric.json`, so `harness2 judge` has something to score; neither file is ever shown to the improver or the selector. Preview what a run would do, without any model calls, with `harness2 run --tasks examples/tasks --k 1 --max-tasks 1 --dry-run`, then drop `--dry-run` to run for real (`--max-tasks` caps tasks per domain, so this runs one task in each of the two domains). You can grade the reconciliation checker by hand with `python3 examples/tasks/data-cleanup/ledger-reconcile/check.py <run_dir>/deliverables`.
